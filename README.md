# Font Manager 🎨

Extension สำหรับ [SillyTavern](https://github.com/SillyTavern/SillyTavern) ที่ให้คุณอัปโหลด/เลือกใช้ฟอนต์เองได้ทั้งฟอนต์ที่ตัวติดต่อผู้ใช้ (UI) ข้อความแชท และโค้ด/โมโนสเปซ แยกจากกันอิสระ — รองรับทั้งอัปโหลดไฟล์ฟอนต์จริง (.ttf/.otf/.woff/.woff2) และวางลิงก์ Google Fonts

## ฟีเจอร์

- **แผงลอยเรียกจากเมนูไม้กายสิทธิ์ 🪄** ข้างช่องพิมพ์ข้อความ ลากย้ายตำแหน่งได้ ไม่ต้องเข้าไปที่หน้า Extensions ทุกครั้ง
- **3 ช่องฟอนต์อิสระจากกัน**: ตัวติดต่อผู้ใช้ (UI) / ข้อความแชท / โค้ด-โมโนสเปซ พร้อมกล่องพรีวิวสดให้ดูก่อนใช้จริง
- **อัปโหลดไฟล์ฟอนต์ได้จริง** ผ่านเซิร์ฟเวอร์ของ SillyTavern เอง (ไม่ต้องพึ่งเว็บฝากไฟล์ภายนอก) — ลากไฟล์วางหรือเลือกได้หลายไฟล์พร้อมกัน
- **รองรับฟอนต์หลายน้ำหนัก/สไตล์** (Regular / Bold / Italic / variable font) ระบบเดาน้ำหนักจากชื่อไฟล์ให้อัตโนมัติ และจัดกลุ่มไฟล์ที่เป็นตระกูลเดียวกันเข้าการ์ดเดียวกันให้เอง
- **วางลิงก์ Google Fonts** ได้ตรงๆ (ระบบดึงชื่อฟอนต์ให้อัตโนมัติ) หรือจะวางลิงก์ไฟล์ฟอนต์ตรงจากที่อื่นก็ได้
- **มีฟอนต์ไทยแนะนำติดตั้งมาให้ในตัว** 14 ฟอนต์จาก Google Fonts (Sarabun, K2D, Mali, Bai Jamjuree, Kodchasan, Itim, IBM Plex Sans Thai Looped, Noto Serif Thai, Maitree, Trirong, Noto Sans Thai, Prompt, Kanit, Playpen Sans Thai) กดปุ่มเดียวเพิ่มเข้าคลังได้ทันที
- **ปรับขนาดตัวอักษรเองได้** โดยไม่ทำให้ไอคอน/ปุ่มต่างๆ ในแอปโตตามไปด้วย
- **ตรวจไฟล์ฟอนต์ที่หายจากเซิร์ฟเวอร์อัตโนมัติ** (เผื่อระบบล้างไฟล์กำพร้าของ SillyTavern ลบไปโดยไม่ตั้งใจ) พร้อมปุ่มอัปโหลดใหม่/ลบทิ้งรายตัว
- รองรับมือถือเต็มรูปแบบ (แผงขยายเต็มจอ ปิดเอฟเฟกต์เบลอที่ไม่จำเป็นเพื่อความลื่นไหล)
- ปิดสวิตช์หลักแล้วเงียบสนิททันที ไม่หลงเหลือสไตล์หรือปุ่มใดๆ ในหน้าเว็บ

## ความต้องการ

- SillyTavern (ทดสอบบนเวอร์ชัน 1.18.0) — ใช้ endpoint มาตรฐานของ ST เอง (`/api/files/upload`, `/api/files/verify`, `/api/files/delete`) ไม่ต้องติดตั้งปลั๊กอินเสริมฝั่งเซิร์ฟเวอร์เพิ่ม

## การติดตั้ง

**ผ่านตัวติดตั้งของ SillyTavern (แนะนำ ถ้ามีลิงก์ repository):**

1. เปิด SillyTavern → ไอคอนส่วนขยาย (ปลั๊กไฟ) → **Install extension**
2. วางลิงก์ repository ของ extension นี้ แล้วกดติดตั้ง

**ติดตั้งด้วยมือ:**

1. ดาวน์โหลด/คัดลอกโฟลเดอร์นี้ทั้งหมดไปไว้ที่ `SillyTavern/public/scripts/extensions/third-party/font-manager/`
2. รีสตาร์ทเซิร์ฟเวอร์ SillyTavern แล้วรีเฟรชหน้าเว็บ (Ctrl+Shift+R เพื่อล้างแคช)
3. เข้าไปที่หน้า Extensions จะเจอดรอเวอร์ "Font Manager 🎨" — ต้องติ๊กเปิดใช้งานก่อน ปุ่มไม้กายสิทธิ์ถึงจะโผล่

## วิธีใช้งาน

1. กดไอคอนไม้กายสิทธิ์ 🪄 ข้างช่องพิมพ์ข้อความ → เลือก **Font Manager** เพื่อเปิดแผงลอย
2. กด **โหลดฟอนต์ไทยแนะนำ** เพื่อดึงฟอนต์ยอดนิยม 14 ตัวเข้าคลังในคลิกเดียว หรือ
   - ลากไฟล์ฟอนต์ (.ttf/.otf/.woff/.woff2) มาวางในกล่อง หรือกด **เลือกไฟล์**
   - วางลิงก์ Google Fonts หรือลิงก์ไฟล์ฟอนต์ตรงในช่องด้านล่าง แล้วกด **เพิ่ม**
3. ที่ช่อง **ตัวติดต่อผู้ใช้ (UI)** / **ข้อความแชท** / **โค้ด-โมโนสเปซ** เลือกฟอนต์ที่ต้องการใช้แยกกันได้อิสระ — ดูผลได้ทันทีในกล่องพรีวิว
4. ฟอนต์ที่มีหลายไฟล์ (เช่น Regular + Bold + Italic) จะถูกจัดกลุ่มไว้ในการ์ดเดียวกันโดยอัตโนมัติ กดลูกศรที่หัวการ์ดเพื่อดู/แก้ไขน้ำหนักแต่ละไฟล์
5. ถ้าอยากปรับขนาดตัวอักษรด้วย ไปที่ดรอเวอร์ในหน้า Extensions → ติ๊ก "กำหนดขนาดตัวอักษรเอง" แล้วเลื่อนแถบปรับขนาด

## ข้อควรรู้

- ลิงก์ไฟล์ฟอนต์จากโฮสต์ที่บล็อก CORS (เช่น Google Drive, Dropbox) จะใช้งานไม่ได้ — แนะนำดาวน์โหลดไฟล์มาอัปโหลดเข้าระบบโดยตรงแทน
- ไฟล์ฟอนต์ที่อัปโหลดจะถูกเก็บไว้ใต้โฟลเดอร์ข้อมูลผู้ใช้ของ SillyTavern (`data/<user>/user/files/`) หากใช้ฟีเจอร์ "ล้างไฟล์กำพร้า" (Data Maid) ของ ST มีโอกาสที่ไฟล์ฟอนต์จะถูกกวาดไปด้วย — extension จะตรวจพบและแจ้งเตือนให้อัปโหลดใหม่โดยอัตโนมัติเมื่อเปิดแผง
- การลากย้ายตำแหน่งแผงจะจำตำแหน่งข้ามการรีเฟรชได้เมื่อเปิดโหมด **"Move UI"** ไว้ในหน้า User Settings ของ SillyTavern (ไม่เปิดก็ยังลากได้ปกติ แค่ตำแหน่งจะรีเซ็ตเมื่อรีเฟรชหน้า)
